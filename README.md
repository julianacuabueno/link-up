### Tech Stack:
- **Frontend:** React, HTML, CSS
- **Backend:** Node.js/Express, DynamoDB
- **APIs used:** Yelp, Google Calendar, Ticketmaster Discovery
- **Deployment:** AWS

### Features:
1. Sync Google Calendar after logging in with your G-mail account
2. View events from Ticketmaster
3. View places based on desired location from Yelp
